# OuiExer (微信聊天记录本地导出工具)

OuiExer 是一款专注于**隐私安全、本地无损解析与多格式导出**的 Windows 微信聊天记录导出工具。

---

## 🌟 核心特性

- 🔒 **全本地运行与零隐私上传**：所有解密、解析、转换与导出操作全部在用户本地单机完成，绝不上传任何聊天正文、图片、视频或密钥。
- 🖼️ **全媒体完整导出**：
  - **图片**：支持微信各类图片格式与解密，无损导出为标准 JPEG/PNG；
  - **视频**：支持视频明文导出（附带 100MB 大小保护）；
  - **语音**：内置本地离线语音识别模型，自动转写并展示时长；
  - **附件与系统消息**：支持文件附件导出，如实保留撤回消息、小程序卡片等。
- 📦 **丰富导出格式**：支持导出为独立交互式 **HTML 聊天包**（含图片视频嵌入）、**Markdown 文件夹包**、**JSON**、**TXT**、**CSV**。
- ⚡ **极致性能与流畅体验**：内置内存切片缓存池与跨会话 LRU 缓存，切换会话与翻阅记录 0ms 秒开。
- 🔄 **透明安全的在线更新**：支持 HTTPS 清单与 64 位 SHA-256 完整性强校验，升级前自动备份。

---

## 💻 系统要求

- **操作系统**：Windows 10 / Windows 11 (64-bit)
- **微信版本**：支持微信 Windows 客户端（如 4.x 及主流版本）

---

## 🚀 使用方法

1. 前往本仓库的 [Releases](https://github.com/swdkhjfm/OuiExer/releases) 页面；
2. 下载最新版本的 `OuiExer.exe`；
3. 打开微信并登录，双击运行 `OuiExer.exe`；
4. 点击主界面【读取登录信息】，选择会话并按需配置导出格式与媒体选项；
5. 点击【开始导出】即可生成完整的聊天记录包。
